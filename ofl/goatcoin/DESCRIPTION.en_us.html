Goatcoin is an ultra-heavy uppercase display face. Built as a strict parametric system - one stem weight, one bar weight, knife-cut corners throughout, and curves reserved for the round family alone - it is designed for headlines, posters and large-format graphic work.

The face carries proportional figures by default with tabular figures available through the tnum OpenType feature, and a slashed zero by default (plain zero via ss02). Lowercase input renders as capitals.

Goatcoin was designed by jtxaeth and is released under the SIL Open Font License. To contribute, see the Goatcoin project repository.
