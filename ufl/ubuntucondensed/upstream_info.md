The font sources are in the **googlefontdirectory-hg** monorepo, a git mirror of the
original Google Code Mercurial repository (`code.google.com/p/googlefontdirectory`)
that was the canonical host for Google Fonts from 2010 to 2013. This family's
source, `Ubuntu-C-designsource.vfb` (with its VTT hinting source
`VTT/Ubuntu-C-hinting.ttf`), is in the Ubuntu family's directory,
`ufl/ubuntu/src/`; its own `src/` holds only `SOURCES.txt`, which describes that
FontLab and VTT pipeline.
